# Pain Care At Home™ — Landing Page

Patient-facing landing page for paincareathome.com. Static HTML — no build step required.

## Structure
- `index.html` — full site (single page)
- `images/` — hero, section, and portrait photos (compressed JPEG)
- `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png` — site icons

## Before going live
1. Square payment links are live for all four paid services — no action needed.
2. Confirm the Open Graph image URL resolves once deployed (`/images/hero-journaling.jpg`).

## Deploy (GitHub → Vercel)
1. Push this folder to a GitHub repository (files at repo root).
2. In Vercel: New Project → import the repo → Framework preset: **Other** → Deploy.
3. Point the paincareathome.com domain to Vercel in Project → Settings → Domains.
